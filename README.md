# hass-wpsd

A Home Assistant integration for [WPSD](https://wpsd.radio), digital radio hotspot control software.

Distributed as a custom repository for [HACS](https://www.hacs.xyz/).

> Work in progress: the repo framework is in place but the integration is not yet implemented.

> [!NOTE] This repo is made with the assistance of an LLM.

## Installation

1. In HACS, add `https://github.com/jhollowe/hass-wpsd` as a custom repository (category: Integration).
2. Install **WPSD** and restart Home Assistant.
3. Add the integration under Settings → Devices & services.
